07   Sketch language rules
DO
Rotate elements slightly (–0.5 to +0.4deg) — cards, titles, buttons, logo

Use clip-path wobbly borders on buttons, cards, theme toggle

Draw SVG annotations in #8a8d9a with #f2740d orange accents, opacity 0.45–0.55

Eyebrow: Courier Prime + flanking orange rules

Margin annotations use Courier Prime 6.5px labels, aria-hidden="true"
DON'T
Use sharp 90° borders on interactive elements — always wobbly clip-path

Use system fonts (Arial, Inter, Roboto) — Caveat / Lora / Courier Prime only

Add coloured backgrounds to sections — all sections inherit canvas background

Mix annotation subject matter — biology notes get biology/chemistry sketches only

Use pure #000 or #fff — always use the token values
08   Theme switching implementation
Storage: localStorage key 'schoolme-theme' · value 'light' or absent (default dark)
Selector: :root[data-theme="light"] overrides all tokens · set via document.documentElement.setAttribute('data-theme','light')
Kaleidoscope: reads document.documentElement.hasAttribute('data-theme') each frame to swap ink RGB
  — Dark ink on light: 30,28,24 · Light ink on dark: 237,233,223
Scroll bar: 1.5px top bar, transform scaleX(scrollY / (body.scrollHeight – window.innerHeight)), orange in both modes
Nav: adds .scrolled class at scrollY > 20 to increase backdrop opacity
